# Hatebu Veil

はてなブックマークのコメント本文をJevで判定し、ユーザーが指定した範囲のコメントを自動で折り畳むChrome拡張機能です。対象は、はてなブックマークのエントリーページです。

## 主な機能

- コメント本文をJevで判定し、攻撃性と有益さをそれぞれ0〜5で評価します。
- 6×6マトリクスで、自動的に折り畳む範囲を設定できます。
- 判定スコアをChromeのローカルストレージにキャッシュし、範囲を変えてもAPIを再度呼ばずに表示を更新します。
- コメントの💣ボタンで手動で隠せます。
- 爆破履歴とseen履歴をマトリクスで確認できます。履歴を参考にフィルター範囲を調整できます。

## プライバシーと通信

- 判定対象としてOpenCode Zen APIへ送信するのはコメント本文のみです。ユーザー名やスター数などのページ情報は送信しません。
- APIキーはChrome拡張機能のローカルストレージに保存します。
- 判定キャッシュにコメント本文そのものは保存しません。
- 判定にはOpenCode Zen APIを使用します。現在対応しているAPIはOpenCode Zen APIのみです。

## 導入方法

1. このリポジトリをダウンロードします。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、ダウンロードしたフォルダーを指定します。
4. 拡張機能のポップアップにOpenCode Zen APIキーを入力して保存します。
5. はてなブックマークのエントリーページを開きます。

## API

現時点ではOpenCode Zen API専用です。他のAPIへの公式対応はありません。

## メンテナンス方針

Jevを試す目的で作った実験的なツールです。継続的なメンテナンス、積極的な機能追加、他APIへの対応、長期的なサポートを行う予定はありません。フォークや改造は歓迎します。

## 開発時の確認

Node.jsがある環境で実行します。

```sh
npm run check
npm test
```

アイコンを変更して生成する場合は、`assets/icon-source.png` を差し替え、`npm ci` と `npm run icons` を実行してください。
